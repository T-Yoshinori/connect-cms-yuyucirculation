# Connect-CMS YuyuCirculation

Connect-CMS向けの非公式「回覧・決裁」プラグインです。所属・グループ・個人を組み合わせた回覧先指定、回答、進行管理、履歴、新着表示、メール通知を提供します。

> バージョン: 0.9.0-beta.1  
> 開発・提供: ゆうゆう企画  
> 状態: ベータ版

## 主な機能

- 複数の所属・グループ・個人を組み合わせた回覧先指定
- 回覧先の追加・削除と重複排除
- 回覧、順次決裁、全員決裁の進行管理
- 回答、差戻し、回覧終了、決裁完了
- 自分が関係する案件のダッシュボードと処理済み履歴
- 承認依頼、回覧受信、差戻し、決裁完了の新着通知
- フレーム設定で有効・無効を選べるメール通知
- テンプレート、設問、添付ファイル

案件は作成者・回覧先・回答者など、その案件に関係する利用者だけが閲覧できます。システム管理者やコンテンツ管理者という理由だけで全案件を閲覧する機能は含みません。

## 対応確認環境

- Connect-CMS 1.44.1
- PHP 8.2

本配布物は新規インストール用です。旧Circulations版または開発版YuyuCirculationの更新には使用しないでください。

必ず検証環境で確認してから利用してください。本番環境へ導入する前に、ファイルとデータベースのバックアップを取得してください。

## インストール

1. Connect-CMSのファイルとデータベースをバックアップします。
2. ZIPを展開します。
3. ZIP内の`app`、`database`、`resources`をConnect-CMSのルートへ重ねて配置します。
4. Connect-CMSのルートで`php artisan migrate`を実行します。
5. `php artisan view:clear`を実行します。
6. 管理画面で「回覧・決裁」を配置し、表示と回答を確認します。

## メール通知

メール通知を使う場合は、Connect-CMS側のメール送信設定が必要です。フレーム設定でメール通知を有効にしてください。無効の場合も、プラグイン内の新着通知は表示されます。
